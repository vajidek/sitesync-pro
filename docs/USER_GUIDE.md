# SiteSync Pro Enterprise ERP - End User Guide

## Overview
Welcome to **SiteSync Pro**, the all-in-one Enterprise ERP for Construction and Mechanical Projects.

Designed & Developed by: **Abdul Vajid EK**

## Module Walkthroughs

### 1. Navigating the Workspace
- Use the left sidebar to switch between core operational modules: **Dashboard**, **Projects**, **Procurement**, **Fleet & Machinery**, **Inventory**, **HR & Payroll**, and **Admin**.
- Access the **AI Assistant** anytime by clicking the glowing ✨ **AI Assistant** button in the top navigation bar.

### 2. Role Switching for Field Teams
SiteSync Pro features an 8-Tier RBAC system:
- **Admin / Manager**: Full executive view, budget overrides, and system configuration.
- **Site Incharge / Supervisor**: Project DPR logs, material requests, and worker attendance.
- **Store Keeper**: Stock inward/outward registers, barcode/QR material receiving.
- **Driver / Operator**: Vehicle fuel logs, odometer updates, and trip sheets.

### 3. Procurement & BOQ Workflows
- Navigate to **Procurement** module.
- Manage **Vendor Directory**, issue **Purchase Requisitions (PR)**, request quotations via **RFQ**, generate **Purchase Orders (PO)**, and record site receipts via **Goods Received Notes (GRN)**.
- Record site measurements using the digital **Measurement Book (MB)** for contractor billing.

### 4. Offline Field Operation (PWA)
When working at remote sites without internet connectivity, SiteSync Pro automatically stores your DPR logs and material issues locally in browser cache. When connectivity is restored, all changes sync automatically to the central ERP.
